# Editorial

Repository-versioned Editorial Source Model.

Editorial content is curated and provides the first release's initial coverage source and quality baseline.

This directory will contain:

- Game editorial dossiers (TypeScript modules)
- Supported query definitions
- Evidence metadata
- Editorial schemas (Zod)

All editorial content is version-controlled as code, not stored in a CMS or database.

Editorial evidence is not necessarily the only future evidence source. Future Community Observations may complement or trigger review of editorial assessments, but must remain distinguishable from editorial evidence and are not implemented in Repository Bootstrap v0.1.

Not yet implemented in Repository Bootstrap v0.1.
