# Architecture Decision Records

This directory will contain Architecture Decision Records (ADRs) documenting key architectural choices.

## Planned ADRs

The following ADRs are candidates for documentation but not yet written:

- **ADR-001** — Static-First Modular Monolith
- **ADR-002** — Repository-Versioned Editorial Baseline + Community Signals Evolution
- **ADR-003** — Deterministic Resolver as Shared Pure Domain Logic
- **ADR-004** — Build-Time Canonical Game Routes
- **ADR-005** — Persistence Introduced Only When Community Observation Storage Is Required
- **ADR-006** — Preview + Production Environment Model
- **ADR-007** — Astro + React Islands as Web Delivery Model

## ADR Format

Each ADR should follow this structure:

```markdown
# ADR-XXX: Title

## Status

[Proposed | Accepted | Deprecated | Superseded by ADR-YYY]

## Context

What problem or decision are we facing?

## Decision

What did we decide?

## Consequences

What are the implications (positive and negative)?

## Alternatives Considered

What other options did we evaluate?
```
